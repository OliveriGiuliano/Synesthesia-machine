# v0 development history

This directory preserves the numbered delivery packets, completion reports, screenshots, measured
JSON, and original design document used to build the first complete product.

These files are historical acceptance evidence. They intentionally retain the terminology, paths,
and scope names that were accurate when recorded; they are not active package, test, example, tool,
or coding-agent boundaries. Start with `AGENTS.md`, `docs/architecture/master.md`, and
`docs/agent-playbooks/README.md` for current guidance.
