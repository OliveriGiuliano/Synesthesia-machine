# ADR-0001: Use CPython 3.12 x64

- **Status:** Accepted
- **Date:** 2026-07-29

## Context

The application needs fast Python iteration and mature Windows wheels. Python 3.14 previously
introduced compatibility risk, while 3.12 remains supported and broadly available.

## Decision

Support 64-bit CPython 3.12 only for version 1 development and packaging. Native NumPy, OpenCV,
and PyAV operations perform frame computation; Python pixel loops are prohibited.

## Consequences

`requires-python` and `.python-version` reject other minor versions. A future change requires an
ADR plus dependency, packaging, and performance validation.
